# Roadmap: October 2026–October 2027

- Preserve attended recovery and fail-closed identity, image and backup checks.
- Expand synthetic negative tests for transport failures and malformed backups.
- Document firmware provenance and separate source releases from hardware acceptance.
- Measure coverage across host scripts and release tooling before claiming Silver coverage.
- Arrange a backup maintainer and a tested access-recovery process.

These are priorities, not delivery promises or claims of completed qualification.
Completed changes are recorded in [CHANGELOG.md](CHANGELOG.md). Propose priorities
through GitHub issues; release decisions follow [RELEASING.md](RELEASING.md).

During this period the project will not add unattended hardware writes,
claim untested device compatibility or replace the upstream platform’s security
responsibilities. New scope requires a public proposal and revised acceptance
criteria.
